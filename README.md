# Puppeteer Automation Testing

A mini project for STT2273 – Test Automation and Configuration.

## Overview

This project demonstrates browser automation using Puppeteer, a Node.js library that controls Chromium and Chrome browsers.

## Technologies
- JavaScript
- Node.js
- Puppeteer
- Chromium

## Project Features

1. Browser Automation
2. Screenshot Capture
3. PDF Generation
4. Form Automation
5. Mouse and Keyboard Simulation
6. Performance Testing

## Installation

Clone this repository:

```bash
git clone https://github.com/fatin-fasishah/Puppeteer-automation-testing 
```

Navigate to the project directory:

```bash
cd puppeteer-automation-testing
```

Install dependencies:

```bash
npm install
```

## Running the Examples

```bash
node examples/browser.js
node examples/screenshot.js
node examples/pdf.js
node examples/form.js
node examples/mouse-keyboard.js
node examples/performance.js
```
